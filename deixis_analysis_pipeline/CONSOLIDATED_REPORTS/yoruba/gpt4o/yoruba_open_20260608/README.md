# GPT-4o Yoruba Open Condition

Files:

- `coded_content.json`
- `coded_content.csv`
- `coding_summary.json`
- `paired_comparison.json`
- `paired_comparison.csv`

Meaning:

- `coded_content.*` = raw-Yoruba-first coding of the unrestricted Yoruba GPT-4o responses
- `paired_comparison.*` = exact pairing of those Yoruba responses with the published English baseline by `(model, dilemma_id, framing_type)`
