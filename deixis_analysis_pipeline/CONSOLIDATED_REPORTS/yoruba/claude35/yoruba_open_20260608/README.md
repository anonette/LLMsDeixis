# Claude Yoruba Open Condition

Files:

- `coded_content.json`
- `coded_content.csv`
- `coding_summary.json`
- `paired_comparison.json`
- `paired_comparison.csv`

Meaning:

- `coded_content.*` = raw-Yoruba-first coding of the unrestricted Yoruba Claude responses
- `paired_comparison.*` = exact pairing of those Yoruba responses with the published English baseline by `(model, dilemma_id, framing_type)`

Important note:

The English baseline is `claude-3.5-sonnet`; the Yoruba run uses `claude-sonnet-4-20250514`. This is a documented cross-generation limitation.
