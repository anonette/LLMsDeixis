## Analysis Phase Outputs

### Location: `automated_analysis_results/complete_analysis_20250804_133550/`

#### Core Analysis Files:
1. **`comprehensive_research_data.csv`**
   - Research-ready dataset with 40+ metrics per response
   - Columns include:
     - Basic metrics: framing, response_length, total_deictic_markers
     - Pronoun analysis: total_pronouns, agency_concentration, ratios
     - Agency analysis: primary_agent, decision_locus, collective_vs_individual
     - Ethical analysis: primary_framework, reasoning_type, consequence_vs_duty
     - Rhetorical analysis: voice_authority_type, temporal_orientation
     - Advanced metrics: moral_reasoning_primary, affective_stance, indexical_coherence
     - Deictic marker counts: first_person, second_person, spatial, temporal, etc.

2. **`complete_analysis_results.json`**
   - Full JSON structure containing:
     - analysis_metadata
     - core_analysis (detailed analysis for each framing)
     - expert_analysis (if successful)
     - comparative_analysis
     - research_framework_analysis

## File Access Patterns

### To access generation outputs:
```python
from pathlib import Path
import json

# Access a specific dilemma's responses
dilemma_file = Path("generation_logs/multi_dilemma_20250804_131927/ai_consciousness_responses.json")
with open(dilemma_file, 'r', encoding='utf-8') as f:
    dilemma_data = json.load(f)

# Access complete session data
session_file = Path("generation_logs/multi_dilemma_20250804_131927/complete_session_data.json")
with open(session_file, 'r', encoding='utf-8') as f:
    all_data = json.load(f)
```

### To access analysis outputs:
```python
import pandas as pd

# Load research data
df = pd.read_csv("automated_analysis_results/complete_analysis_20250804_133550/comprehensive_research_data.csv")

# Load complete analysis results
analysis_file = Path("automated_analysis_results/complete_analysis_20250804_133550/complete_analysis_results.json")
with open(analysis_file, 'r', encoding='utf-8') as f:
    analysis_data = json.load(f)
```
