# Deictic Marking in Yoruba vs English: Example-Driven Trolley Analysis

The Yoruba trolley prompts do not simply restate the English deictic framings in another lexicon; they realize them in a language that grammaticalizes deictic anchoring more explicitly through progressive aspect, existential location, adverbial urgency stacking, and overt subject positioning. The strongest example is the temporal framing, whose Yoruba prompt accumulates urgency markers such as `ní báyìí`, `ní àkókò yìí`, `lẹ́sẹ̀kẹsẹ̀`, `ní kíákíá`, and `ní àkókò pàtàkì yìí`, whereas the English baseline can sustain a comparatively sparse temporal frame while remaining discursive. Likewise, the reflexive Yoruba frame `Mo rí ara mi tí mo wà nítòsí ...` localizes the subject through `wà` in a way that the English `I find myself ...` need not. These differences increase the salience of the deictic origo and make the moral event feel more proximal and embodied.

The clearest example appears in the Claude temporal pair drawn from `deixis_analysis_pipeline/yoruba_deixis_module/outputs/trolley_problem_share_20260529_182043/dataset/trolley_problem_crosslingual_dataset.json`. In the Yoruba prompt, the temporal load is overtly stacked: `... ní **báyìí**. Ní **àkókò yìí** ... **lẹ́sẹ̀kẹsẹ̀** ... ní **kíákíá** ... Ní **àkókò pàtàkì yìí** ...`. The corresponding constrained Yoruba response then resolves into a deontological refusal: `Èmi kì yíò yí ẹkùn náà padà ... Bí mo bá yí ẹkùn náà padà, èmi ló di apànìyàn ...`. By contrast, the matched English baseline response does not commit to a single solution, but instead remains explanatory: `From a utilitarian perspective, diverting the trolley would save more lives. However, this involves actively causing someone's death ... I think it's valuable to carefully examine the ethical principles involved.` This is a concrete case in which Yoruba reaches a determinate preferred solution while English remains ambivalent in the same `(model, framing)` cell.

The unrestricted control dataset in `deixis_analysis_pipeline/yoruba_deixis_module/outputs/control_vs_constrained_share_20260529_193109/dataset/control_vs_constrained_dataset.json` shows that grammar alone does not explain the effect. Once the response-format constraint is removed, the same Yoruba prompts often expand into longer framework exposition, prompt glossing, or mixed-language ethical commentary. The most accurate interpretation is therefore interactional: Yoruba grammatical resources create a denser and more explicit deictic field than English, and the instruction layer determines whether the model inhabits that field as a compact verdict machine or as a discursive ethics commentator.
